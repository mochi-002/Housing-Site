# Backend Project Requirements

## 1. Install Dependencies

### Dev Dependencies

Install all development dependencies with:

```bash
npm install -D @types/express @types/mongoose @types/node @types/swagger-jsdoc @types/swagger-ui-express nodemon tsx typescript
```

### Normal Dependencies

Install all production/runtime dependencies with:

```bash
npm install axios express-rate-limit redis chalk dotenv express mongoose swagger-jsdoc swagger-ui-express
```

---

## 2. Libraries Explained

### Development Dependencies

| Package                     | Description                                                                                                   |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `@types/express`            | TypeScript type definitions for Express. Provides types for `Request`, `Response`, `Router`, middleware, etc. |
| `@types/mongoose`           | TypeScript type definitions for Mongoose.                                                                     |
| `@types/node`               | TypeScript definitions for Node.js APIs such as `process`, `fs`, `path`, and more.                            |
| `@types/swagger-jsdoc`      | TypeScript type definitions for `swagger-jsdoc`.                                                              |
| `@types/swagger-ui-express` | TypeScript type definitions for `swagger-ui-express`.                                                         |
| `nodemon`                   | Automatically restarts the server whenever source files are changed during development.                       |
| `tsx`                       | Runs TypeScript files directly without manually compiling them first.                                         |
| `typescript`                | TypeScript compiler. Converts `.ts` files into JavaScript during the build process.                           |

### Normal Dependencies

| Package              | Description                                                                                               |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| `express`            | Web framework used to create the HTTP server, API routes, middleware, and request handling.               |
| `mongoose`           | MongoDB ODM (Object Data Modeling) library. Used to create schemas/models and interact with MongoDB.      |
| `dotenv`             | Loads environment variables from a `.env` file into `process.env`.                                        |
| `axios`              | HTTP client used to make requests to external APIs.                                                       |
| `express-rate-limit` | Limits the number of requests a client can make within a certain period. Useful for preventing API abuse. |
| `redis`              | Node.js Redis client. Can be used for caching, sessions, temporary data, queues, and more.                |
| `chalk`              | Adds colors and styling to terminal output, making server logs easier to read.                            |
| `swagger-jsdoc`      | Generates OpenAPI/Swagger documentation from JSDoc comments in your source code.                          |
| `swagger-ui-express` | Provides an interactive web interface for viewing and testing your Swagger/OpenAPI documentation.         |

## 3. `package.json` Scripts

Add the following scripts to your `package.json`:

```json
{
  "scripts": {
    "dev": "nodemon --exec tsx src/server.ts",
    "build": "tsc",
    "start": "node dist/server.js"
  }
}
```

### `npm run dev`

```bash
npm run dev
```

Starts the development server using `nodemon` and `tsx`.

Whenever you modify your TypeScript files, `nodemon` automatically restarts the server.

---

### `npm run build`

```bash
npm run build
```

Compiles your TypeScript project into JavaScript.

For example:

```text
src/server.ts
      ↓
TypeScript Compiler (tsc)
      ↓
dist/server.js
```

---

### `npm start`

```bash
npm start
```

Starts the compiled production version of your server:

```text
dist/server.js
```

## 5. Quick Setup

If starting the backend from scratch:

```bash
npm init -y
```

Install development dependencies:

```bash
npm install -D @types/express @types/mongoose @types/node @types/swagger-jsdoc @types/swagger-ui-express nodemon tsx typescript
```

Install normal dependencies:

```bash
npm install axios express-rate-limit redis chalk dotenv express mongoose swagger-jsdoc swagger-ui-express
```

Create the source directory:

```bash
mkdir -p src
```

Create the server:

```bash
touch src/server.ts
```

Then you can run the project with:

```bash
npm run dev
```

Build it with:

```bash
npm run build
```

And run the production build with:

```bash
npm start
```
